Lunar Shield 2.0 — filter-source attribution and formats

Lunar ships its own small domain-rule collection, not the external subscriptions
below. External filter text is downloaded as data only after the user explicitly
enables a source (which also opts in to background freshness checks) or requests
its update. Compiled caches and original source text/attribution comments remain
in the local user profile. Publisher hosts see the list download and IP address;
Lunar does not send visited URLs, titles or request URLs to those hosts.

For both EasyList-family subsets, Lunar accepts supported ABP hostname/URL
patterns, resource/domain/first-/third-party constraints and @@ network
exceptions. Cosmetic/element hiding, scriptlets, full regular expressions,
HTML/CSP/response rewriting, redirects, removeparam and executable directives are
excluded and counted as unsupported. Comments/headers are retained in raw caches
but not executed. Downloads and compilation are bounded; excluded-rule counts
are shown per source. Changes are network-only adaptations, not upstream claims.
When redistributing downloaded/modified data, comply with the chosen license:
attribute the EasyList authors and retain notices, including share-alike for
CC-BY-SA or corresponding-source obligations under the GPL option.

Download / cache policy
Built-in downloads use fixed public GitHub repository Contents API endpoints and
raw content negotiation. GitHub can rate-limit or fail requests. Custom
subscriptions are separate, deliberate user choices on a restricted public HTTPS
host allowlist; their publishers retain all rights and licensing obligations.
Never redistribute a custom source without checking its own license.

Sources are not downloaded in full on every launch. Enabled stale sources are
checked at most daily on startup/explicit enable, with conditional ETags when
available; users may explicitly request an earlier check. Last successful data
and last check times are displayed separately. Invalid data, failed compilation
or failed cache persistence do not replace an active last-good engine. A local
download/check timestamp is not independent verification of upstream freshness,
coverage, accuracy or completeness. Source data is not included in installers.
