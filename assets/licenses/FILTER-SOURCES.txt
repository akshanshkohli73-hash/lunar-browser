Lunar Shield — optional filter sources

The application ships Lunar's own small domain rules. Optional third-party filter
text is not bundled and is fetched only after the user selects a source and
requests an update. It is stored in the user's profile; no browsing URLs are sent
to list hosts. Supported network-only rules are parsed by @ghostery/adblocker.

StevenBlack Unified Hosts
Source: https://github.com/StevenBlack/hosts
MIT-licensed repository; included source lists retain their own licensing and
attributions. See upstream readme/license before redistributing the aggregate.
Lunar converts validated domain entries to ABP hostname-anchor network rules.

Both sources are downloaded from fixed public GitHub Contents API endpoints.
GitHub may rate-limit requests. Updates are manual, bounded and validated; failed
updates retain the last valid cached rules. A local cache timestamp is a download
time, not an independent verification of upstream completeness or freshness.
