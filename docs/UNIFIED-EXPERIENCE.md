## Privacy / source boundaries

- Network ABP subset only: resource types, hostname/path/regex patterns, third-party/domain conditions and exceptions are exercised. Unsupported cosmetic, scriptlet, redirect/replace/removeparam, HTML and CSP modifications are excluded. No full EasyPrivacy/ABP compatibility, universal/video ad blocking, fingerprinting/anonymity or Brave-parity claim.
- EasyPrivacy uses only `easyprivacy_general.txt`, `easyprivacy_thirdparty.txt`, `easyprivacy_trackingservers.txt`, `easyprivacy_allowlist.txt`, not the full subscription. Attribution is **The EasyList authors (https://easylist.to/)**; upstream dual license is GPL-3.0-or-later OR CC-BY-SA-3.0-or-later. Cached adaptation comments preserve attribution/source/license. Maintained list text is not shipped; it is fetched only after explicit user selection/Refresh.
- `assets/licenses/{FILTER-SOURCES,THIRD-PARTY-NOTICES}.txt` document sources and bundled runtime licenses. `scripts/third-party-notices.mjs` generates actual installed runtime license text and fails on missing notices; packaging includes and validates those assets. The Ghostery MPL source is available in the exact-version npm packages/upstream repository.
- Third-party cookie protection strips **network Cookie/Set-Cookie headers**, not JavaScript storage access or full partitioning. Pausing Shield disables that site's Shield policies. HTTPS upgrading is opt-in, for eligible public top-level HTTP navigations only, with local/IP/private/test/auth/custom-port exclusions and no silent HTTP fallback. A redirected request is not proof of successful TLS.
- Recent-site display is separately opt-in; history recording still follows the existing preference. Weather sends manually configured coordinates only on explicit consent/Update to a fixed provider. Live weather/provider responses were not verified here.
- Filesystem checks do not claim immunity against a hostile process racing writes with the same OS user's privileges. Profile reset/pruning and data clearing are logical deletion, not forensic erasure.
